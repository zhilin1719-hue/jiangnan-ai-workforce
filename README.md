# 江南理工 · AI 编制优化 43 岗情景

面向约 300 人教育集团的独立战略讨论网站。当前情景是在原 23 岗门槛上追加 20 岗，累计压减 43 岗，期末编制约 257 人。按每岗年全成本 12 万元、首年平均生效 9 个月估算，首年人力成本减少 387 万元，稳定年化减少 516 万元。上述数字均为压力测试情景，并非集团已核准的岗位或人员决定。

## 在线访问

- 方案首页（43 岗交互测算）：<https://zhilin1719-hue.github.io/jiangnan-ai-workforce/>
- 实施周期与项目报价：<https://zhilin1719-hue.github.io/jiangnan-ai-workforce/implementation.html>

## 本地运行

任意静态服务器均可，例如 `python -m http.server 8765`，然后打开 <http://localhost:8765>。

## 发布

GitHub Pages 从 `main` 分支根目录发布。无构建步骤、无数据库、无第三方前端依赖。
