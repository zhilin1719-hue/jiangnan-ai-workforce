# 江南理工 · AI 编制优化 43 岗情景

面向约 300 人教育集团的独立战略讨论页面。当前情景是在原 23 岗门槛上追加 20 岗，累计压减 43 岗，期末编制约 257 人。按每岗年全成本 12 万元、首年平均生效 9 个月估算，首年人力成本减少 387 万元，稳定年化减少 516 万元。上述数字均为压力测试，并非集团已核准岗位或人员决定。

## 本地运行

用任意静态服务器运行此目录，例如 `python -m http.server 8765`，打开 `http://localhost:8765`。

## 发布

GitHub Pages 从 `main` 分支根目录发布。无需构建、数据库或第三方前端依赖。

## 内容

- `index.html`：方案与来源
- `styles.css`：响应式深色设计
- `app.js`：本地测算、流程切换、CSV 导出
- `board-deck.pptx` / `execution-plan.docx` / `workforce-model.xlsx`：可编辑汇报、执行方案和测算表

不采集访问者表单内容；情景参数仅在浏览器当前页面计算。研究检索时间为 2026 年 9 月。图片为生成的概念视觉，非集团真实校区。此页面并非集团官方公告。
